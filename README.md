# Apple TV-лаунчер для Android TV (Xiaomi Mi Box S)

Власний головний екран у стилі Apple TV, який майже нічого не вантажить, і маленька програма, що вмикає кнопки пульта.
Перевірено на Xiaomi Mi Box S (2-ге покоління, Android 11).

**Що вміє лаунчер**
- Плитки програм з анімацією, справжні фото на фоні з дуже повільним рухом, зміна фото кожні 5 хвилин.
- Матове скло на верхній панелі й у меню: розмитий фон під ними.
- Привітання, годинник, погода (Open-Meteo; місто за IP або вручну).
- Wi-Fi у верхній панелі: список мереж, підключення, пароль екранною клавіатурою.
- «Усі програми» — кнопка Apps на пульті.
- Заставка з великим годинником і погодою, коли ви нічого не чіпаєте.
- Пам'ять 70–90 МБ, у спокої майже не навантажує процесор.

**Що вміє програма кнопок («Key Launcher», 12 КБ)**
YouTube → YouTube, Netflix → Netflix, Apps → «Усі програми», Xiaomi TV+ → Київстар ТБ, Prime Video → Megogo.

## Як поставити на новий телевізор

Потрібен комп'ютер (Mac або Linux) в одній Wi-Fi мережі з телевізором.

1. На телевізорі: Налаштування → Про пристрій → кілька разів натисніть «Збірка» → з'явиться «Для розробників» → увімкніть **Налагодження USB** (або «Налагодження по мережі»). Дізнайтесь IP: Налаштування → Мережа.
2. Скачайте репозиторій (зелена кнопка Code → Download ZIP) і розпакуйте, або:
   ```
   git clone <адреса цього репозиторію>
   cd <папка>
   ```
3. Запустіть (замініть адресу на свою):
   ```
   sh setup.sh 192.168.1.50
   ```
   На екрані телевізора спливе запит — виберіть «Завжди дозволяти» і «ОК».

Скрипт сам: завантажить adb (якщо його немає), встановить обидві програми, видасть їм дозволи, закине фото, ввімкне програму кнопок, зробить лаунчер головним екраном і виставить системні налаштування (див. нижче).

Додатково:
```
sh setup.sh 192.168.1.50 --city Київ --lat 50.4501 --lon 30.5234   # своє місто для погоди
sh setup.sh 192.168.1.50 --clean                                    # ще й прибрати зайві програми Xiaomi
```
Без `--city` місто визначається за IP.

Програми для плиток (YouTube, Netflix, Lampa, Київстар ТБ, Megogo, ClearVPN) встановлюйте з Google Play — плитки з'являться самі. Список і порядок плиток — у файлі `/sdcard/PcHome/config.json` на телевізорі (зразок: `config.example.json`).

## Що скрипт змінює в системі
| Налаштування | Навіщо |
|---|---|
| `hdmi_control_auto_language_change_enabled 0` | телевізор більше не міняє мову приставки (раніше скакала на китайську/японську) |
| анімації вікон 0.7 | трохи жвавіше |
| `screen_off_timeout 900000` | системна заставка не перебиває заставку лаунчера |
| `location_mode 3` | Android показує список Wi-Fi лише за ввімкненої геолокації (лаунчер її нікуди не передає) |
| лаунчер за замовчуванням | кнопка Home відкриває його |

З `--clean` вимикаються (не видаляються назавжди) 33 зайві програми Xiaomi (список у `tools/bloat-xiaomi.txt`): оболонки Xiaomi, аналітика, Spotify, Apple TV, Amazon Video та інші. Повернути одну: `adb shell cmd package install-existing --user 0 <пакет>`. Службу оновлення прошивки (`com.xiaomi.mitv.updateservice`) скрипт не чіпає.

## Якщо кнопка пульта не реагує
Пульти відрізняються кодами кнопок. Подивитись код кнопки:
```
adb logcat -s KeyLauncher
```
натисніть кнопку — з'явиться рядок `key=190 KEYCODE_BUTTON_3`. Поправте коди на початку `keymap/src/ua/pc/keymap/KeyService.java` (`KEY_YT`, `KEY_NF`, `KEY_APPS`, `KEY_A`, `KEY_B`) і зберіть заново. Для Mi Box S: YouTube = 190, Netflix = 193, Apps = 284, Xiaomi TV+ = 192, Prime Video = 194.
Кнопки через `adb shell input keyevent` програма не бачить — перевіряйте справжнім пультом.

## Збірка з вихідного коду
Потрібні JDK 11+ та Android SDK (build-tools і platforms):
```
ANDROID_HOME=~/Library/Android/sdk sh build.sh
```
Скрипт сам створить ключ підпису в `keys/` (його немає в репозиторії) і покладе готові файли в `apks/`. Готові `apks/*.apk` у репозиторії підписані автором; якщо поставите свою збірку поверх них, спершу видаліть стару програму з телевізора.

## Склад
- `launcher/` — лаунчер (Java, без бібліотек).
- `keymap/` — програма для кнопок (служба доступності).
- `assets/wallpapers/` — 12 фото з Wikimedia Commons; автори й ліцензії в `CREDITS.txt` (переважно CC BY-SA — при поширенні залишайте підписи).
- `tools/` — список зайвих програм Xiaomi, скрипт очищення кешу.
